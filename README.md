## Playing a modpack?

If you're playing a modpack, please don't open an issue here yourself. Tell the modpack maker about the problem and let them file it. They picked the mods, versions and configs, so they can check whether it's really my mod or their setup.

Modpack developers are welcome to file issues here. Include the pack name and version, and the mod versions it uses.

## How to file an issue

1. Search the [open and closed issues](../../issues?q=is%3Aissue) for your problem first.
2. Press **New issue** and pick the form that fits. There's no blank issue on purpose; each form asks for what I need to reproduce the problem.
3. Fill in every required field and submit.

| Form | Use it when |
| --- | --- |
| Bug report | A feature of a mod behaves wrong and the game keeps running. |
| Crash report | Minecraft closes, hangs on load or shows a crash screen. |
| Compatibility problem | A mod of mine and another mod don't work together. |
| Feature request | You want a mod to do something it doesn't. |

## What to have ready

- The mod name and version. It's in the jar file name and on the mod list screen.
- The Minecraft version, the mod loader (NeoForge, Fabric or Forge) and the loader's own version.
- Your log. `logs/latest.log` in the instance folder, or `crash-reports/` for a crash. Upload long files to [mclo.gs](https://mclo.gs) and paste the link.
- Your other mods or the modpack name and version.
- Steps that make it happen, starting from a new world if you can.

I close reports that miss the version, loader or log until they're added, because I can't tell which build you ran.
